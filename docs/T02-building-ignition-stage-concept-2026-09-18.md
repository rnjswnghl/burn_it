# T02 · 건물 점화 스테이지 콘셉트

## 변경 목적

불꽃 모양 커서를 따라 자유롭게 문지르는 방식에서 명확한 목표와 보상이 있는 스테이지 게임으로 전환했다. 사용자는 평면 선화 속 작은 `YOU` 캐릭터가 되어 건물마다 정해진 점화 포인트를 모두 찾아 불을 붙인다.

## 게임 루프

1. 흰 배경의 선화 건물과 번호가 표시된 주황색 점화 포인트 확인
2. 일반 포인터로 각 점화 지점을 클릭
3. 점화할 때마다 `N / 전체 LIT` 진행률과 해당 위치의 불꽃 확인
4. 모든 포인트를 점화하면 건물 전체에 자동으로 불꽃 확산
5. 약 3초 동안 활활 타는 건물을 감상
6. `STAGE CLEAR` 표시 후 다음 건물로 이동

## 스테이지

- **Stage 01 · 야근 오피스:** 4개 점화 포인트
- **Stage 02 · 학교 본관:** 5개 점화 포인트
- **Stage 03 · 회사 연구동:** 6개 점화 포인트
- **사용자 이미지:** 이미지 영역 비율에 맞춘 4개 점화 포인트 자동 배치

## 시각과 조작

- 사용자가 싫어한 불꽃 모양 커서를 완전히 제거
- 기본 crosshair와 점화 지점 위의 pointer 커서 사용
- 점화 포인트는 번호, 원, 십자선으로 표시
- 점화가 끝난 지점은 주황색 원과 체크 표시로 전환
- 모든 지점 완료 후 포인트 UI를 숨기고 평면 3색 불꽃과 탄화 경계를 집중 노출
- 건물 옆에 간단한 선화 `YOU` 캐릭터 배치

## 검증

- 불꽃 커서 DOM 제거 확인
- Stage 01의 네 지점 순차 점화와 `4 / 4 LIT` 확인
- 자동 전소와 `STAGE CLEAR` 노출 확인
- 다음 버튼으로 학교 본관 이동 확인
- 회사 연구동 직접 선택 확인
- 전소 애니메이션 중 61fps 확인
- 닉네임 룰렛과 LocalStorage 회귀 테스트 통과
