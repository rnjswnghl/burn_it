# T02 · 활활 타는 불꽃과 직장 스트레스 장면

## 변경 목적

작은 성냥불처럼 보이던 상호작용을 스트레스 해소 목적에 맞는 강한 불꽃으로 바꾸고, 추상적인 마감·걱정·메시지 대신 직장인이 바로 알아볼 수 있는 업무 공간을 태우도록 개선했다.

## 불꽃 효과

- 성냥 모양 포인터를 여러 갈래 불꽃 포인터로 교체
- 소각 지점마다 생성되는 초기 불티를 4개에서 10개로 증가
- 활성 불꽃 비율을 6개 지점당 1개에서 2개 지점당 1개로 증가
- 불꽃 높이·폭·광원을 확대하고 일부 지점에 보조 불꽃 혀 추가
- 불티의 속도, 수명, 크기와 색상 변화를 확장
- 불꽃이 더 오래 유지되면서 탄화 영역이 빠르게 이어지도록 조정

## 준비된 장면

1. **야근 사무실:** 밤 9시 47분에도 켜진 모니터와 책상, 창문, OVERTIME 문구
2. **끝없는 회의:** 긴 회의 테이블, 참석자, 일곱 번째 회의 슬라이드
3. **쌓인 업무:** 책상을 가득 채운 서류 더미와 URGENT 문구

모든 장면은 외부 이미지를 쓰지 않고 Canvas 2D로 실시간 그린다. 흰 종이 배경 위에 다중 패스 선, 미세한 위치 흔들림, 서로 다른 굵기, 사선 해칭, 점묘를 조합해 펜과 마커가 섞인 손그림 질감을 만들었다.

## 검증

- JavaScript 구문 검사 통과
- 첫 방문 닉네임 룰렛 회귀 테스트 통과
- 기본 장면이 야근 사무실인지 확인
- 회의실·업무 더미 전환 확인
- 불꽃 드래그 후 실제 소각 진행률 증가 확인
- 강한 불꽃과 선화 화면 캡처 확인
