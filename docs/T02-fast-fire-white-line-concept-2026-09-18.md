# T02 · 빠른 불꽃과 흰색 선화 콘셉트

## 변경 목적

소각 효과가 많아질수록 마우스 반응과 프레임 속도가 느려지던 문제를 해결하고, 전체 화면을 흰색 배경과 거친 선 중심으로 정리했다. 첨부된 불꽃 참고처럼 외곽 빨강, 중간 주황, 안쪽 노랑이 분리된 평면 불꽃을 적용했다.

## 성능 개선

- 드래그 소각 지점 간격을 6px에서 14px로 조정
- 유기적 소각 경계 샘플 수 축소
- 그을음 경로를 지점별로 채우지 않고 색상 레이어별 단일 경로로 합성
- 커버리지 계산을 매 프레임에서 10프레임마다 한 번으로 변경
- 불씨 개수에 상한을 적용하고 고비용 개별 그림자 제거
- 애니메이션 불꽃은 화면 분포를 유지하면서 제한된 수만 렌더링
- 그라디언트와 광원 효과를 평면 3색 불꽃으로 교체

자동 검증의 동일한 최악 조건에서 약 7fps였던 프레임 속도가 최종 61fps까지 개선됐다.

## 반복 클릭 점화

- 클릭만 해도 해당 위치에 즉시 불꽃 생성
- 0.52초 안에 82px 이내를 다시 클릭하면 연속 점화로 판정
- 최대 6단계까지 불꽃 묶음, 크기, 소각 반경과 불씨 증가
- 상태 문구로 `연속 N번 점화` 피드백 제공

## 시각 콘셉트

- 페이지와 캔버스 배경을 완전한 흰색 `#FFFFFF`로 통일
- 종이 노이즈를 매우 약하게 낮추고 검은 선을 중심으로 구성
- 선택 메뉴의 검은 면 채움을 제거하고 선, 이동, 주황 밑줄로 상태 표시
- 불꽃은 빨강 `#E92B12`, 주황 `#FF7900`, 노랑 `#FFD32A`의 평면 레이어
- 업무 공간은 서로 다른 굵기, 흔들림, 해칭, 점묘의 펜 선으로 유지

## 검증

- JavaScript 구문 검사 통과
- 첫 방문 닉네임 룰렛 회귀 테스트 통과
- 같은 위치 4회 연속 클릭 감지 확인
- 스트레스 조건 렌더링 61fps 확인
- 세 가지 업무 장면 전환 및 소각 진행률 증가 확인
