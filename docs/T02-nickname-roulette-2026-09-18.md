# T02 · 첫 방문 닉네임 룰렛

## 변경 목적

첫 방문자가 곧바로 게임 인트로로 들어가던 흐름을 닉네임 생성부터 시작하도록 바꿨다. 계정이나 소셜 로그인을 요구하지 않고 브라우저의 LocalStorage로만 사용자를 기억한다.

## 구현

- 형용사 / 명사 / 두 자리 숫자로 구성한 3열 슬롯 룰렛
- 레버와 버튼 모두 동일한 룰렛 동작 제공
- 열마다 멈추는 시간을 다르게 두어 실제 슬롯처럼 순차 정지
- 닉네임 확정 전 게임 진입 차단
- 확정된 닉네임과 지난 소각 기록을 LocalStorage에 저장
- 재방문자는 저장된 이름을 불러오고 인트로로 바로 이동
- 기존 헤더의 주사위 버튼으로 언제든 랜덤 닉네임 재생성
- Sites 방문 권한을 공개로 전환해 ChatGPT 로그인 없이 접속 가능

## 디자인

- 기존 Paper / Ink 흑백 시스템을 유지
- 슬롯 프레임과 레버는 거친 검은 선으로 표현
- 불꽃색 `#FF4D00`은 숫자, 레버 손잡이, 확정 이름에만 사용
- 각진 프레임, Georgia italic, 손글씨 계열 한글로 투박하고 정갈한 인상 유지

## 검증

- 첫 방문: 닉네임 룰렛 화면 노출, 인트로 숨김
- 룰렛: 세 열 순차 정지, 닉네임 생성 및 확정 버튼 활성화
- 저장: `burnit:user:v1`에 확정 닉네임 기록
- 재방문: 새로고침 후 인트로 화면으로 진입
- 로그인: ChatGPT 로그인 UI 및 관련 앱 코드 없음
- 화면 캡처: `screenshots/burnit-nickname-roulette.png`

## 배포 주소 참고

Sites 프로젝트의 URL 라벨은 이미 `burnit`이다. 현재 Sites가 생성한 공개 주소에는 워크스페이스 경로가 자동으로 포함된다. 별도 소유 도메인을 연결하지 않는 한 플랫폼이 발급한 주소 형식이 사용된다.
